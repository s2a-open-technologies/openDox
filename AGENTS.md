# openDox: Agent Guide

Medical transcription platform. **License: AGPL-3.0-or-later**, Author: `Christopher Abanilla <christopher.abanilla@gmx.de>`.

## Quick Start

```bash
# Docker (recommended)
docker compose up --build

# Local dev - two terminals:
# Terminal 1: Backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 5000
# Terminal 2: Frontend  
cd frontend && npm run dev
```

## Stack
- **Backend**: Python 3.12+, FastAPI, SQLModel, Alembic
- **Frontend**: React 18, TypeScript, Vite, shadcn/ui, Tailwind CSS
- **DB**: PostgreSQL (Docker) or SQLite fallback (`test.sqlite3`)
- **AI**: External Whisper API (Docker), external LLM via LangChain
- **Auth**: JWT (python-jose + bcrypt), optional LDAP

## Critical Entrypoints

**Backend**: `main.py` → `backend/run.py:create_app()`
- Only valid entrypoint. Do NOT use `uv run main.py` (causes double init)
- Mounts static files on `/` (not `/static`) with `html=True` for SPA catch-all
- Auto-runs Alembic migrations on startup

**Frontend**: `frontend/src/main.tsx`
- Path alias `@/` → `src/`
- Dev proxy: `/api/v1/` → `http://localhost:5000`
- Build output: `frontend/dist/` → copied to `static/`

## Developer Commands

```bash
# Backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 5000
```

## Key Architecture

**Static Files**: `backend/run.py` mounts `StaticFiles(directory="static", html=True)` on `/`. The `html=True` handles SPA routing (serves `index.html` for 404s). Exception handler skips `/api/` routes.

**ROOT_PATH (Sub-path Deployment)**: Set `ROOT_PATH=/opendox` in `.env` or Docker env. The backend injects `window.__ROOT_PATH__` into `index.html` at startup — no frontend rebuild needed. `api.ts` reads this at runtime and patches `window.fetch` to prefix all `/api/` calls. The WebSocket in `Recorder.tsx` imports `BASE_PATH` from `api.ts`. Do NOT use `VITE_ROOT_PATH` build arg — it's runtime-injected now.

**Auth**: JWT tokens in `localStorage`. Frontend fetches `/api/v1/auth/me` on mount. NEVER hardcode `userId="1"`.

**Transcription Pipeline**:
1. Browser records via `MediaRecorder` + `AudioWorklet`
2. Live: WebSocket sends chunks to Whisper API
3. Final: Backend concatenates chunks, re-transcribes, sends to LLM

**ASR**: Factory pattern (`asr_factory.py`). Backends: `openai_compatible.py` (external API) or `disabled.py` (no live transcript).

## Environment

Copy `.env.example` → `.env`:
- `DATABASE_URI` overrides SQL_* components
- `WHISPER_API_ENDPOINT` / `WHISPER_API_KEY` fallback when DB settings are `None`
- `{VAR}_FILE` suffix reads from file (Docker secrets)

## Known Gotchas

- **Dev server**: Always `python -m uvicorn main:app`, never `uv run main.py`
- **Port 9000**: Often occupied (Jupyter). Use `9100:9000` in `docker-whisper.yml`
- **Whisper settings**: DB values take precedence over `.env`. Clear DB or use Settings UI if stale.
- **WebSocket**: Frontend uses `BASE_PATH` from `api.ts` + `window.location.host`. Vite proxy handles `ws: true`.
- **Microphone**: Requires HTTPS (except localhost). `Permissions-Policy` header set in middleware.
- **LLM**: Fresh `OllamaModel()` instance per task (in `background_transcription_service.py`), not singleton.

## Frontend Conventions

- **UI**: shadcn/ui components in `src/components/ui/`
- **State**: `useAuth()` from `AuthContext.tsx` is source of truth
- **Disclaimer**: "Kein Medizinprodukt" required in recording dialog AND transcript view
- **Logo**: `Logo.tsx` animated SVG - don't remove `width`/`height` attributes

## Build Artifacts

- `static/` and `frontend/dist/` are in `.gitignore` (regenerated by Docker/build)
- Static assets (logos) live in `frontend/public/`, copied to `static/` on build
- `uv.lock` exists and should be committed for reproducible builds

## Python Coding Standard

All Python code follows these conventions for readability and maintainability.

### 1. Import Structure

Group imports strictly with blank lines between groups:

```python
# 1. Standard Library
import os
import json
from typing import List, Dict, Optional

# 2. Third-Party Imports
import requests
import pandas as pd
from fastapi import FastAPI
from sqlmodel import Session

# 3. Custom Imports (Local Modules/Packages)
from backend.components.models.user_model import User
from backend.components.security.hashing import get_password_hash
```

### 2. Function Structure (PEP 257 & Type Hinting)

Every function must use type hints and Google-style docstrings:

```python
def process_user_data(data: Dict[str, str], threshold: float = 0.5) -> List[int]:
    """Process user data and filter by threshold.

    Args:
        data: Dictionary with source data.
        threshold: Filter threshold. Default is 0.5.

    Returns:
        List of processed IDs passing the filter.

    Raises:
        ValueError: If input dictionary is empty.
    """
    if not data:
        raise ValueError("Data dictionary cannot be empty.")
    
    # Logic here...
    results = [1, 2, 3] 
    
    return results
```

### Key Rules

- **PEP 8**: Use `snake_case` for functions/variables, `PascalCase` for classes
- **Type Hints**: Always use return types (e.g. `-> None`, `-> bool`)
- **Docstrings**: Use Google-style (as shown above) - most readable for LLMs and humans
- **Line Length**: Keep under 88 characters (Black formatting)
